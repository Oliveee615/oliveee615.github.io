# It's Just Me — 个人作品集网站

这是一个从零设计的中文优先、响应式单页作品集原型。

## 运行方式
- 直接用浏览器打开 `index.html` 即可预览。
- 如需本地开发服务器：在此目录运行 `python3 -m http.server 8000`，然后打开 `http://localhost:8000`。
- 可部署至 Vercel、Netlify 或任意静态网站托管服务。

## 当前交互
- 2025 / 2026 年份卡片悬停高亮、点击切换作品列表。
- 可按“全部经历 / 学校项目 / 实习经历”筛选。
- 点击项目卡片，以沉浸式覆盖页面查看项目详情；按 Esc 或右上角 × 关闭。
- 适配桌面与手机屏幕，并支持减少动态效果的系统偏好。
